# Images Directory

## Required Images

### Profile Picture
- **File**: `profile.jpg`
- **Location**: `/public/images/profile.jpg`
- **Specs**:
  - Format: JPG or PNG
  - Recommended size: 800x800px (square)
  - Max file size: 500KB
  - Aspect ratio: 1:1 (will be displayed as circle)

**Note**: Please add your professional profile picture as `profile.jpg` in this directory.

## Image Guidelines
1. Use high-quality, professional photos
2. Ensure good lighting and clear background
3. Compress images for web performance
4. Use appropriate file formats (JPG for photos, PNG for logos/badges)
